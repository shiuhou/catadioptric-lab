# CAD 曲线导出视觉强调设计

## 目标

让使用者在「方案与导出」一眼找到可用于 SolidWorks / CAD 的 XYZ 镜面截面文件，并识别完整参数表中决定曲线的字段。

## 范围

- 为「镜面截面采样」增加主操作视觉层级，保留其原有 XYZ 导出行为。
- 高亮 `scale`、`a0`、`b0`、`lo`、`hi`、`rin0`、`rout0` 七项曲线核心参数。
- 未启用字段仍显示未启用；高亮不改变计算、导出、导入或本地保存逻辑。

## 验收

- 构建的 `index.html` 包含 XYZ 主操作与七个曲线核心行标记。
- `npm run check` 成功。
- 桌面和窄屏都能阅读按钮与表格标签，且不产生横向溢出。
